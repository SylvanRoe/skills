# 二创提示词说明（rewrite prompts）

> 本文件是人读版的提示词说明；机器实际加载的是 **`prompts.json`**（rewrite.py 读取）。两者内容对应，改平台/强度请优先改 `prompts.json`。
>
> 调用方式：`python scripts/rewrite.py 文案.txt --platform <平台> --style <强度> [--backend <后端>]`
> 无 API key 时默认只生成提示词文件，可直接粘给任意大模型或人工执行。

---

## 0. 通用前置约束（所有二创任务都带上）

1. **忠于原意**：只重组、提炼、改写表达，不得捏造原文没有的事实、数据、人名。
2. 中文为主（YouTube 场景需额外产出英文 SEO 内容）。
3. 若原文信息不足以支撑某段，明确标注「（原文未提及）」而不是脑补。
4. **原创度**：不得直接大段照抄原文，需经过结构与措辞的实质性改写（避免平台查重）。

---

## 1. 结构化知识笔记（`--mode notes`）

产出 500~1500 字结构化学习笔记：一句话主旨 → 3~6 个核心观点（观点+依据）→ 保留关键数据/专有名词 → 「一句话总结」+ 2~3 条行动建议。可独立阅读。

## 2. 思维导图大纲（`--mode mindmap`）

产出 Markdown 层级大纲（最多 4 层，节点用 ≤12 字短语），可直接粘进 XMind / 幕布 / mermaid mindmap。

---

## 3. 多平台二创（`--mode rewrite`，4 平台 × 3 强度）

改写强度三档：
- **light 轻度**：保留原结构与信息，仅口语化、去水词、通顺化（最接近原文）。
- **medium 中度**：重组结构、加钩子与过渡、平台化表达（平衡原创度与保真，默认）。
- **heavy 重度**：只保留核心信息点，重叙事、立人设/观点、强情绪（原创度最高）。

### 3.1 小红书（xiaohongshu）

图文笔记。文风：亲切口语、短句分行、emoji 点缀、第一人称「姐妹们/亲测/真心」；结构：共鸣开头 → 分点干货 → 总结推荐；结尾 5~8 个 `#` 话题标签。
- 轻度：保留结构，口语化去水词，出标题(3备选)+正文+标签。
- 中度：重组结构、加钩子、小红书化表达。
- 重度：重叙事、立人设、强情绪，可切「我亲测」第一视角。

### 3.2 抖音（douyin）

短视频口播脚本。文风：快节奏、强网感、口语化、适合配音；结构：黄金 3 秒钩子 → 3~5 个分镜段落（标【镜头】+ 画面/配音）→ 互动引导（点赞/评论/关注）。
- 轻度：保留原意，去水词通顺，基本节奏，分镜标注。
- 中度：加黄金 3 秒钩子、重组分镜、节奏化。
- 重度：重叙事、强情绪/冲突、玩梗与热门句式，含反差钩子→分镜→高潮→互动引导。

### 3.3 哔哩哔哩（bilibili）

中长视频稿。文风：信息密度高、逻辑清晰、适度玩梗、弹幕友好；结构：开场抛问题/反差 → 分段（带小标题）→ 金句与总结；可引导「一键三连」。
- 轻度：保留结构，去水词通顺，加分段小标题。
- 中度：重排为带小标题章节、提升信息密度与逻辑、加梗点。
- 重度：重叙事、立人设/观点鲜明、强逻辑与金句、互动设计。

### 3.4 YouTube（youtube）

视频方案（中英双语）。产出：中文脚本 + 英文标题(3 备选) + 英文描述(含关键词与 CTA) + 英文标签(8~12) + 章节时间戳。
- 轻度：中文脚本(保留结构去水词) + 英文标题/描述/标签/章节。
- 中度：中文脚本重组分段加钩子 + SEO 英文描述 + 章节。
- 重度：强钩子中文脚本(高原创) + 吸睛英文标题 + SEO 描述 + 12 标签 + 章节。

---

## 4. 给 Agent / 开发者

- 想让任意模型自动调用本 skill：把 `references/tool_schema.json` 的 3 个函数注册为工具（`vse_transcribe` / `vse_fetch_media` / `vse_rewrite`）。
- 想换默认模型或接私有化 LLM：改 `rewrite.py` 的 `BACKENDS` 或传 `--base-url --model --api-key`。
- 想加新平台/新风格：在 `prompts.json` 的 `platforms` 下加一项即可，无需改代码。
